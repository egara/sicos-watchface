# Project Documentation Overview

Welcome to the documentation for **sicos-watchface**, a custom Wear OS watch face built using the official **Watch Face Format (WFF)** standard for the Pixel Watch 3.

## Documentation Index

1. **[Architecture](ARCHITECTURE.md)**: Project packaging, file structure, WFF specification version, and declarative XML hierarchy.
2. **[Design System](DESIGN_SYSTEM.md)**: Visual specifications, coordinates, typography, palettes, complication slots, and Always-On Display (AOD) behavior.
3. **[Environment & Tooling](ENVIRONMENT.md)**: NixOS reproducible environment (`shell.nix`), build instructions, and wireless ADB deployment to the Pixel Watch 3.
4. **[Changelog](CHANGELOG.md)**: Iteration log tracking each milestone, feature addition, and bugfix.
